# Algoritmos agregados

Además del monitor (`monitoreo_actividad_bancaria.py`), este repositorio incluye:

1. `deteccion_fraude.py`: calcula señales y una puntuación educativa de riesgo.
2. `encriptacion_segura.py`: cifra datos con Fernet; requiere `pip install -r requirements.txt`.
3. `autenticacion_segura.py`: hash de contraseñas con PBKDF2 y tokens aleatorios.
4. `monitoreo_actividad_bancaria.py`: registra anomalías de actividad.
5. `validacion_transferencias.py`: valida datos antes de procesar una transferencia.

Estos ejemplos son educativos y no sustituyen sistemas bancarios certificados, revisión humana, MFA ni asesoría del banco. No introduzcas datos reales, contraseñas, claves o números de cuenta en el repositorio.
